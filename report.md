# Data Analysis Report

For this assignment, I worked with a dataset named nominations.csv, part of a 2026 Grammy Awards dataset provided in a previous lab's instructions. Each row represents a creative work: who made it, which award category it belongs to, and whether anyone else was involved. I started with head(), info(), and describe() after loading everything into pandas. Those commands told me which columns were numeric, where values were missing, and how consistently everything was formatted.

Once the structure made sense, I began interacting with the data more deliberately. I used loc and iloc to pull specific rows and slices, and even though both methods achieve similar outcomes, they require slightly different thinking. At that point, the real exploration started. I applied Boolean filters, including one that combined multiple conditions using the & operator, to isolate a very specific subset of nominations. Then I created a new column generated from the existing data, later removed another column using .drop(), and double checked the column list to ensure the DataFrame looked exactly the way I intended. The last step was running a groupby() analysis to compare how many works featured guest collaborators versus those created without them, and there were far fewer collaborations than I expected. It made me wonder: are solo works more likely to be nominated, or do collaborative pieces simply occur less often?

Of course, no dataset is perfect. There were missing values in certain fields, especially where featured artists were supposed to appear, which limits how deeply some patterns can be analyzed. Still, the data was organized enough to work with smoothly, and the structure hinted at a bigger relational system connecting categories and artists. Overall, working with this dataset made the process surprisingly engaging. It’s one thing to manipulate generic numbers, but it’s another to explore information tied to real-world events, culture, and recognition.
